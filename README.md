# Escape Room Phone

Open `index.html` on a phone or host this folder on a local web server. The default correct number is:

```text
5552328057
```

To change it, edit `app.js` and replace this line:

```js
correctNumber: "5552328057",
```

Put your recordings in the `assets` folder using these exact filenames:

```text
assets/correct-call.mp3
assets/wrong-number.mp3
```

The app expects MP3 audio files.

On iPhone or Android, open the page in the browser and choose the browser option to add it to the Home Screen. It will launch like a standalone phone prop.
